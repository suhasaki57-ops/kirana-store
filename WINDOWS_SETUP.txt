STEP 1: INSTALL NODE.JS (5 minutes)
═══════════════════════════════════════════════════════════════════════════════

1. Download Node.js:
   https://nodejs.org/dist/v20.20.0/node-v20.20.0-x64.msi

2. Double-click the downloaded .msi file

3. Click through the installer (accept all defaults)

4. IMPORTANT: Restart PowerShell after installation

5. Verify installation - open PowerShell and type:
   node --version
   
   (Should show: v20.20.0 or similar)

═══════════════════════════════════════════════════════════════════════════════
STEP 2: SETUP FREE MONGODB DATABASE (5 minutes)
═══════════════════════════════════════════════════════════════════════════════

1. Sign up FREE at:
   https://www.mongodb.com/cloud/atlas/register

2. Create a Free Cluster:
   • Click "Build a Database"
   • Choose "M0 FREE" tier
   • Click "Create"

3. Create Database User:
   • Go to "Database Access"
   • Click "Add New Database User"
   • Username: ecomuser
   • Password: ecom123456
   • Click "Add User"

4. Allow All IPs:
   • Go to "Network Access"
   • Click "Add IP Address"
   • Select "Allow Access from Anywhere"
   • Confirm: 0.0.0.0/0

5. Get Connection String:
   • Go to "Database" tab
   • Click "Connect" button
   • Choose "Connect your application"
   • Copy the connection string
   • Should look like:
     mongodb+srv://ecomuser:ecom123456@cluster0.xxxxx.mongodb.net/...

6. Update backend/.env file:
   • Open: backend/.env
   • Find line starting with: MONGODB_URI=
   • Replace entire line with your connection string
   • Add /ecommerce before the ? like:
     mongodb+srv://ecomuser:ecom123456@cluster0.xxxxx.mongodb.net/ecommerce?...
   • Save file

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ERROR: "node: command not found"
FIX:  Restart PowerShell after installing Node.js

ERROR: "Cannot connect to MongoDB"
FIX:  1. Check MongoDB Atlas IP whitelist has 0.0.0.0/0
      2. Verify connection string in backend/.env
      3. Make sure password is correct

ERROR: "Port 5000 already in use"
FIX:  Open PowerShell and run:
      netstat -ano | findstr :5000
      taskkill /PID <number> /F

ERROR: "npm install fails"
FIX:  1. Delete node_modules folder
      2. Delete package-lock.json
      3. Run: npm install again
