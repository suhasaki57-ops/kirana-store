STEP 1: Set up MongoDB Atlas (5 minutes) - REQUIRED
═════════════════════════════════════════════════════════════════════════════════════

1. Go to: https://www.mongodb.com/cloud/atlas/register
2. Sign up (free)
3. Create a FREE M0 cluster
4. Create database user:
   - Username: ecomuser
   - Password: ecom123456 (or your choice)
5. Network Access → Add IP → Allow access from anywhere (0.0.0.0/0)
6. Database → Connect → Copy connection string
   
   It will look like:
   mongodb+srv://ecomuser:ecom123456@cluster0.XXXXX.mongodb.net/?retryWrites=true&w=majority

7. Edit this file:
   c:\Users\admin\OneDrive\Desktop\New folder (2)\backend\.env

8. Find this line:
   MONGODB_URI=mongodb+srv://ecomuser:ecom123456@cluster0.xxxxx.mongodb.net/ecommerce?retryWrites=true&w=majority

9. Replace it with your actual connection string
   IMPORTANT: Add "/ecommerce" before the "?" like:
   mongodb+srv://ecomuser:PASSWORD@cluster0.XXXXX.mongodb.net/ecommerce?retryWrites=true&w=majority

10. Save the file
